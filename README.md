# DevConf 2026

A responsive conference website for DevConf 2026, built using HTML5 and CSS3.

## Live Demo

🔗 [View Live Website](https://samiaforge.github.io/assignment-01-devconf-2026/)

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive design
- Clean and modern user interface
- Navigation bar
- Hero section
- Conference information section
- Speaker section
- Event details
- Registration section
- Footer section
- Responsive layout for different screen sizes

## Dependencies

This project does not require any external dependencies.

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/samiaforge/assignment-01-devconf-2026
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. You can also use the Live Server extension in VS Code to run the project locally.
